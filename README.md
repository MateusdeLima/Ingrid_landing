# 🏋️‍♀️ Ingrid Lemos - Landing Page Profissional

> **Landing Page de Alta Conversão para Personal Trainer & Consultoria Fitness**  
> Projeto web completo, moderno e responsivo, desenvolvido e em produção para a profissional **Ingrid Lemos** (CREF 175457-G/SP).

---

## 📋 Sobre o Projeto

A **Ingrid Lemos Landing Page** foi projetada com foco em autoridade de marca, apresentação clara de serviços e facilidade de captação de novos alunos[cite: 33]. O site apresenta a trajetória profissional de Ingrid[cite: 33], modalidades de atendimento (Consultoria Online, Treinamento Presencial e Treino Funcional)[cite: 34], programas especializados[cite: 35], prova social com avaliações reais[cite: 36], área de FAQ interativo[cite: 37] e integração direta para contato via WhatsApp e Instagram[cite: 38].

## ✨ Destaques & Funcionalidades

- [x] **Design Moderno e Dark Mode:** Interface elegante em tons escuros que valorizam a fotografia e o nicho fitness[cite: 32, 33].
- [x] **Navegação Fluida (Smooth Scroll):** Âncoras responsivas para rolagem suave até cada seção[cite: 32].
- [x] **Conversão Direta:** Links estratégicos para iniciar conversas no WhatsApp com mensagens pré-configuradas[cite: 34, 38].
- [x] **Accordion Interativo (FAQ):** Respostas expansíveis para melhorar a usabilidade[cite: 37].
- [x] **Totalmente Responsivo:** Ajuste ideal para smartphones, tablets e desktops.
- [x] **SEO & Performance:** Estrutura otimizada para carregamento rápido em navegadores móveis.

## 🛠️ Tecnologias Utilizadas

A stack técnica foi selecionada para garantir velocidade extrema e excelente legibilidade do código:

| Tecnologia | Função no Projeto |
| :--- | :--- |
| **[React 18](https://react.dev/)** | Biblioteca principal para criação de componentes modulares de UI. |
| **[TypeScript](https://www.typescriptlang.org/)** | Tipagem estática para maior segurança e facilidade na manutenção. |
| **[Vite](https://vitejs.dev/)** | Ferramenta de build de altíssima performance para desenvolvimento e bundle final. |
| **[Tailwind CSS](https://tailwindcss.com/)** | Framework CSS utility-first para estilização rápida, moderna e responsiva. |
| **[Lucide React](https://lucide.dev/)** | Pacote de ícones vetoriais leves e minimalistas[cite: 32, 33, 34, 38]. |
